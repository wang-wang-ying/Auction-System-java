# Auction-System-java
# Java-拍卖系统（管理后台+用户前台）
管理后台基于 Spring Boot 提供后台管理服务，用户前台基于 Vue3 + Element Plus 提供 Web 端应用。项目围绕拍卖业务的全生命周期展开，涵盖商品发布与审核、拍卖场次管理、在线竞价、保证金冻结、成交结算、订单流转、数据统计等核心业务。

通过本项目，你将体验到基于 Spring Boot 的 Java 后端开发流程与 Vue3 的前端开发，帮助你打下坚实的全栈开发基础，并加深对企业级应用架构的理解。

此外，本系统还集成了权限控制模块，支持基于角色（RBAC）的菜单、按钮级权限分配，确保不同账号只能访问和操作自己权限范围内的数据。
### 1、系统功能
⭕ 管理后台

· 登录

· 首页（数据统计大盘）

· 保证金管理：保证金记录 | 充值

· 用户管理：用户列表 | 冻结/解冻

· 订单管理：订单列表 | 发货 | 取消

· 成交管理：成交记录 | 确认成交

· 出价记录：竞价记录查询

· 拍卖场次管理：场次列表 | 新增/编辑/取消

· 商品分类管理：分类列表 | 新增/编辑/删除

· 商品管理：商品列表 | 商品审核 | 新增/编辑

· 系统管理：账号管理 | 角色管理 | 菜单管理

⭕ 用户前台（Web 端）

登录/注册 | 首页 | 拍卖商品 | 拍卖场次详情 | 商品列表 | 商品详情 | 在线出价 | 保证金充值 | 保证金冻结 | 我的出价 | 我的订单 | 订单支付 | 确认收货 | 用户中心

### 2、技术栈与工具
本项目采用稳定且广泛应用的技术栈，结合 Java 后端开发与 Vue3 前端开发，确保开发流程清晰、系统稳定。

技术选型

· 后端：Java 21 + Spring Boot 2.7

· 数据库：MySQL 8.0

· 前端：Vue3 + Element Plus + Vite + Pinia + Vue Router + ECharts

· 构建工具：Maven 3.9

· 开发工具：VSCode / IntelliJ IDEA
